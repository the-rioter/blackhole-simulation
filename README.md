A real-time 3D black hole simulation built with C++ and OpenGL 3.3.

## Features

- Gravitational lensing approximation
- Dynamic accretion disk
- Tidal disruption of stars
- Debris streams and accretion
- Interactive 3D camera
- Real-time orbital simulation
- Adaptive rendering quality
- Designed to run on low-end hardware

## Technologies

- C++
- OpenGL 3.3
- GLSL
- GLFW
- GLAD

## Goal

Explore astrophysics, physics simulation, and real-time computer graphics while maintaining good performance on modest hardware.

## Status

Active development.
